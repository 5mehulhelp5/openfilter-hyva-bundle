# OpenFilter for Hyvä (bundle)

One Composer require for [OpenFilter](https://github.com/iranimij/openfilter) on Hyvä: `iranimij/openfilter` (core), `iranimij/openfilter-hyva` (Hyvä storefront) and the shared core `iranimij/module-base`.

> **Status: in development (1.0 planned).** Install instructions arrive with 1.0.0.
