# OpenFilter for Hyvä (bundle)

One Composer require for [OpenFilter](https://github.com/iranimij/openfilter), the free MIT layered navigation for Magento 2 and Hyvä: `iranimij/openfilter` (core), `iranimij/openfilter-hyva` (Hyvä storefront) and the shared base module `iranimij/module-base`.

```bash
composer require iranimij/openfilter-hyva-bundle
bin/magento setup:upgrade
bin/magento indexer:reindex catalogsearch_fulltext
```

Requirements, quick start and documentation: [OpenFilter](https://github.com/iranimij/openfilter#readme). Issues: [iranimij/openfilter](https://github.com/iranimij/openfilter/issues) (triaged within 7 days, no SLA).
