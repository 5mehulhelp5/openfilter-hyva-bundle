# Contributing

This metapackage only lists OpenFilter's packages. Code, issues and pull requests live in [iranimij/openfilter](https://github.com/iranimij/openfilter) (core) and [iranimij/openfilter-hyva](https://github.com/iranimij/openfilter-hyva) (Hyvä storefront); their [CONTRIBUTING](https://github.com/iranimij/openfilter/blob/main/CONTRIBUTING.md) applies here too, including the clean-room rule.
